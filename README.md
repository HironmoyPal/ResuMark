## ✨ Introduction

AI Resume Analyzer is a modern web application that allows users to:

- Upload and manage resumes securely.
- Evaluate resumes against job listings.
- Receive custom ATS scores and AI-driven feedback.
- Interact with a clean, reusable, and responsive interface.

This project is fully client-side, leveraging Puter.js for authentication, storage, and AI evaluation — no backend setup required.

---

## ⚙️ Tech Stack

- **[React](https://react.dev/)** – Build dynamic, reusable components with a virtual DOM.
- **[React Router v7](https://reactrouter.com/)** – Handle nested routes and seamless navigation.
- **[Puter.js](https://jsm.dev/resumind-puterjs)** – Client-side SDK for auth, storage, database, and AI features.
- **[Tailwind CSS](https://tailwindcss.com/)** – Utility-first CSS framework for responsive and modern UI.
- **[TypeScript](https://www.typescriptlang.org/)** – Static typing for better code quality and scalability.
- **[Vite](https://vite.dev/)** – Fast development server and build tool.
- **[Zustand](https://github.com/pmndrs/zustand)** – Lightweight state management for React.

---

## 🔋 Features

- **Easy Authentication**: Fully client-side auth with Puter.js.  
- **Resume Upload & Storage**: Securely upload and store resumes.  
- **AI Resume Matching**: Receive ATS scores and detailed feedback.  
- **Reusable Components**: Modular and maintainable UI structure.  
- **Responsive Design**: Works perfectly across all devices.  
- **Modern UI/UX**: Clean layout using Tailwind CSS and shadcn/ui.
